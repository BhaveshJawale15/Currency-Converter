# Currency-Converter
A sleek, responsive, and real-time Currency Converter web application built using HTML5, CSS3, and modern JavaScript (ES6+). This application allows users to instantly convert amounts between different global currencies with up-to-date exchange rates.

🚀 Features (वैशिष्ट्ये)
Real-time Exchange Rates: Fetches live currency data dynamically using a reliable, free currency API.
Dynamic Flag Updates: The country flags automatically change whenever a user selects a different currency from the dropdown menu.
Smart Input Validation: Automatically handles empty or invalid amount inputs by defaulting to a minimum value of 1.
Fully Responsive Design: Optimized for a seamless experience across mobile devices, tablets, and desktops.
Clean & Modern UI: Built with a professional color palette, elegant shadows, and smooth hover effects.

🛠️ Tech Stack (वापरलेले तंत्रज्ञान)
Frontend: HTML5, CSS3
Scripting: JavaScript (ES6+) — Fetch API, Async/Await, DOM Manipulation
API Used: @fawazahmed0/currency-api for real-time exchange rates
Icons & Flags: FontAwesome (Icons) and FlagsAPI (Country Flags).
